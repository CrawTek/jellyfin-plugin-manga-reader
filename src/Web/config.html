Manga Reader

To add manga, open Dashboard → Libraries → Add Media Library, choose Manga, and select its folder using Jellyfin’s folder picker.

Manga uses Jellyfin’s Books library type internally. Select its library tile in Jellyfin Web or the Android phone/tablet app to read. Each account keeps its own saved page.

Enable an existing Books library

After updating the plugin, restart Jellyfin and fully close and reopen the Android app. CBZ/ZIP supported; CBR, PDF, loose image folders and TV apps are not supported.
